# Retenum

A shared commercial record for two parties: what was agreed, what changed, what was authorised,
what was delivered, and what was paid.

**Status:** MVP in development (Slices 0, 1 and 1A complete). Not yet released.

## Where to start

| Document | Purpose |
|---|---|
| `RETENUM_PRODUCT_DECISIONS.md` | Product direction, market, jurisdiction, payment model (Bachs), open issues |
| `RETENUM_PRD.md` | Requirements with IDs used in code and tests |
| `RETENUM_TECHNICAL_ARCHITECTURE.md` | Stack and technical decisions |
| `RETENUM_BUILD_PLAN.md` | Slice-by-slice plan and execution log with real test results |
| `RETENUM_RISK_REGISTER.md` | Risks and mitigations |
| `RETENUM_DESIGN_SYSTEM.md`, `RETENUM_UI_UX_SPECIFICATION.md` | Visual design system, screens and interaction patterns |
| `RETENUM_PRODUCT_DISCOVERY.md`, `RETENUM_OPERATING_MODEL.md`, `RETENUM_PHASE_3_VALIDATION_PLAN.md` | Discovery research (desk research only) |

The application lives in [`app/`](app/README.md).
